# Matriz de funciones demostrables

| Módulo | Implementado en esta DEMO | Fuera del alcance |
|---|---|---|
| Dashboard | Conteos SQL y balances por moneda | Pronósticos, cotizaciones, fiscalidad |
| Clientes | Alta, edición, baja y filtro | DNI/CUIT real, importación/identificación legal |
| Expedientes | Registro, actualización, búsqueda, estados y vínculo | Integraciones judiciales, expediente electrónico oficial |
| Documentos | Editor de texto, estado, vínculo, guardar/borrar en RAM | DOCX, PDF, versiones de producción, firmas |
| Agenda | Eventos, fechas manuales, filtros y edición | Plazos judiciales validados o recordatorios del SO |
| Finanzas | ARS/USD/EUR, ingresos, egresos, balance por moneda | Facturación real, comprobantes fiscales, conversión |
| Seguridad | Datos simulados, SQL parametrizado y memoria temporal | Usuarios, PIN, RBAC, cifrado, backup, recuperación |

Para probar un caso, utilizar nombres inventados, referencias `DEMO-*` y direcciones `example.invalid`. No presentar cifras y datos del programa como resultados de clientes reales.
